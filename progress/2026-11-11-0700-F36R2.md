# F36, second gate round: nothing to choose, the command check, the lock, the drawn size

- **No choice, no tap.** `settle` refuses a clash whose two statements are the same once cleaned; the page draws
  such a clash as one plain note with neither statement (`Standing::is_choice`). The app's own copy is gone.
- **The command check** is core's `command.rs`: a plain file, never a link, not setuid or setgid, owned by the owner
  of the person's home, every folder from the root down closed to group and others unless sticky, links walked.
  `delivery.md` says what is not looked at: folder owners, the gap before the write, Windows.
- **The lock** waits 3 seconds by the clock; one that is old, dated ahead or unreadable is taken; a folder at its
  name refuses after the same wait. `pages` is made 0700 only behind the lock.
- **A kit fault the renders showed.** The drawing painted an option at its role's size, not the smaller one the
  layout measured, so lines ran past the bubble. A run now carries its `size`; `tests/draw.rs` holds it.
- **Lesson, held by tests.** Each stated property got the case that fails without it (`f35/lock.rs`,
  `f35/delivery.rs`, core's `hook/tests.rs`). A render is read with the drawing's own measure, not the bundled one.
- **Not proved.** A file of another account (the test uses the root folder as the home). The delivery tests need
  the folders above Cargo's target folder closed to group and others: a umask of 002 would fail them.
