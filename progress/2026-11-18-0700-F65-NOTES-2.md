## What was built

1. **A mark with no number takes no folder for the made one (the blocker, Windows).**
   - *What is so, by reading.* A making that finds its file gone reaches `by_another` on every system: nothing
     before it asks the system. There the folder at the name was taken for the made one when its mark was the
     made one's. Off Unix a mark was `(0, 0, time of making)`, so the time alone decided. `f65/alone.rs`'s
     second round writes a line for the folder put in place, in the same text a making lists by (the round of
     `a_line_a_hand_wrote…` passes on Windows only if those two texts are one). So on Windows that round ends
     `MOVED` only when the folder put in place has another time of making than the made one, and ends as
     listed, exit 0, when Windows hands it the old time, as ADR 0020 says CI once showed.
   - *Why the job was green.* Not seen: nothing here ran on Windows, and no log of that job was read. The only
     reading the code leaves is that in that run the folder put in place had a time of its own. So the round
     did not pin the rule on Windows: it passed or failed by what the file system remembered of the name.
   - *With a test that needs no Windows.* The rule is now one function of two marks, `made_still`. As PR 201
     merged it (the two marks are one), its test was red at "a time alone told two folders as one".
   - *The fix.* A mark is the system's number for the folder, or none, and the time. `made_still` is true only
     when the made folder's mark holds a number and the mark now there is the same. Windows has no number, so
     a making whose file is gone ends `MOVED`, exit 1, as before PR 201, whatever the list holds.
   - *At the binary.* `f65/mark.rs`'s making whose folder an `add` listed meanwhile now expects `MOVED`, exit 1
     and nothing changed where a folder has no number. That needs no sleeping and does not lean on the time: on
     Windows the answer is the same whatever the time is. It was run here with the number taken out of `mark`
     (mutation 7b), not on Windows.
