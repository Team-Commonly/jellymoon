# Live work: the wait shows the work

## Built
- **Core keeps the steps** (`run/steps.rs`). A `tool_use` block of an `assistant` line, after the start is a run's
  and in a line that is not skipped, whose `name` is one of `Edit`, `Glob`, `Grep`, `Read`, `Write` (a closed enum,
  `Tool`) is a step. Of `Edit`, `Read` and `Write` the file is kept only as core's cleaned name of a file inside the
  run's copy (the folder as given or as the system names it), relative, every part a plain name, cleaned by
  `obeyed::named`; anything else is no name and the step is still counted. Every step is counted, the last 4 kept.
- **The handover.** The stream's reader writes `runs/<id>/steps.json` whole (`hook::put`) at each line that brought a
  step; `jellymoon_core::doing(home, day)` reads it for each made wish whose record is of that wish and day, read
  back as this shape only, within 4 KiB, every name cleaned again. An answered run goes on counting; a follow-up is a
  new run and counts from zero. The
  file stays as it was at the run's end. `Stream::read` wraps `take`; `take`, the end and the last word are untouched.
- **The kit** gains `Character::says` and `PieceKind::Says`: one line on a pill over a busy character, in the room its
  art reaches above it, where no other piece is placed; none over stars and none where the room is lower than the
  pill. `label` and the new `says` share one `pill`.
- **The app** (`app/src/live.rs`), at each drawing of a day's page (`Today::draw`, `made_alone`), only when a made
  wish is working: each working made wish's little one says its last step ("reading b.txt", or "thinking"), and a
  told note `steps-<wish>` of the newest one goes just before the note that says it is being worked on. Nothing can
  be tapped; once the run has ended none of it is drawn.
