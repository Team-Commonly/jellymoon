# F45: the eleven findings of its gate

On branch `f45-keep-fix`, one commit on top of `db51e1b` (F45 as built). The gate on F45 failed it with eleven
findings, four of them blocking. This commit closes them. The account is `docs/development/keep.md`; what was
decided and measured is ADR 0017, "Found by the gate on F45".

## What changed

- **What is switched off is read where the step runs** (`copy/git.rs`: `Git::opened`, `Repo::seen_from`). A
  linked worktree's own config is read through that worktree's git folder, and every git a keep starts is given
  the names from both. A config with more than 8 KiB of names, or a `=` in one, is refused in its own words.
- **A file's filter is asked as git reads attributes when it writes** (`copy/keep/attrs.rs`, new): four readings,
  any `filter` refuses.
- **The step and what is found after it** moved to `copy/keep/step.rs` (new). When git took the step and the
  meant branch is not at the commit, `HEAD` is asked: the work is kept where it landed (`How::Elsewhere`,
  `How::Loose`), and the record's `onto` may be the one word `HEAD`.
- **One rule for a branch name a record holds** (`copy::nameable`), for the writer and the reader.
- **The trial runs on a refreshed copy of the index** (`copy/keep/fits.rs`): a touched file is no unsaved change,
  and `--ask` takes no lock on the person's index.
- **Words**: the late refusal, a lock that cannot be made, a config that cannot be switched off, a branch name no
  record holds, a name of only spaces or marks.
- **The cut hook** reads its variable only in a build with debug assertions.

## What the next session should know

1. **F46 (`run toss`) builds on this.** Names it may use that changed are listed in the commit's report: `Unkept`
   has three variants more (`NoLock`, `Config`, `Unnamed`), `How` two more, `copy::nameable` and `copy::LOOSE` are new, `Git::open` is unchanged.
2. **A record's `onto` may be `HEAD`**, only with `work: kept`. A reader of records that expects a branch there
   must take it.
3. **Not run**: Windows and Linux by hand, git 2.38 and 2.39, real LFS, a sparse checkout. Three of the four
   scenes of "A step git stops" are from git's own account and were not run.
4. **`keep.md`, "What is not closed"** has what stays open: an attributes file changed between check and step, a
   name of only dots on an old git.
