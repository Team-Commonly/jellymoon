# The walk: the window's loop with no window (walk)

## Built
- `app/examples/walk.rs`: makes the calls `window.rs` makes, in its order, through `Showing`, against a real core in
  the home the environment names (`Today::from_env`), and writes a picture at each `picture:<name>` step with the
  kit's windowless drawing. Steps: `type:`, `chip:`, `enter`, `start`, `folder:`, `look`, `until:<state or
  note>:<seconds>`, `poke:<wish id>`, `tap:<note>:<option>` (only a placed option), `picture:`. One line a step:
  the step (typed words counted, a folder not named), milliseconds, note titles, each wish's state.
- `app/Cargo.toml`: the example, `required-features = ["sticker-kit/headless"]`, so CI's Mac test run
  (`--features sticker-kit/headless`) builds it for the test. The brief said `["headless"]` (the app's feature,
  as `snapshot`); with that, no CI run builds it and `tests/walk.rs` could never find it.
- `app/tests/walk.rs` (macOS only): a whole loop on a made-up home through the door (new project named, a wish
  entered, `until:done`, `poke:m1`, `Keep it`), the made-up agent's `told` script ending with a result; and a bound
  that passes. Nothing moved out of `window.rs`: the entry's wiring (the chosen chip, the project waiting for its
  chip) is a few lines of the example's own.
- `docs/development/app.md`: a short section under "What the window does, with no window".

## Red first
Both tests failed with "the walk example is not built" before it existed.

## Mutations (one hold, `tests/walk.rs`)
| Mutation | Killed by |
|---|---|

| `until`'s bound ignored | the bound test (the walk outlives its 20 s) |
| every picture written before the steps | both (identical pictures; `never.png` written) |
