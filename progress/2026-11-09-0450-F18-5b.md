# F18 PR 5b: layout.spec, the top bar's session, and F18

**Changed.** `web-e2e/layout.spec.ts` holds the two layout invariants (no horizontal page scroll; no clipped text) and runs at 390 and
1440 px. Clipped is defined in the spec's header and in browser-specs.md: an element with text of its own, or an ancestor, hides
overflow (hidden or clip) and the text runs past it, sideways or down; scrolling boxes do not clip, and a line that ellipsizes with a
`title` is allowed. It is measured on the text's own rectangle with 1px of tolerance. Routes and states: `/device` (signed out, signed
in, with an error, approved), `/pod/:id` (an unbroken 101-character headline, an unfolded body, an ask with its consequence line, the
confirm row, a long draft in the composer), the needs-you filter (one ask, then nothing left), `/invite/:token` (signed out, signed in,
spent), and the top bar under a pod id of 202 characters, signed out and in. Every check also asserts the shell's banner is there. A
first test plants a clipped box, a titled ellipsis and a 3000px element in a page, so the check is shown to catch what it should.
The pod test also shows the card's status chip, its receipt chip and a folded body, the parts step 3 names.
The top bar (`App.tsx`) shows the real session: "Signed in", or a Sign in link to `/v1/auth/github/start?next=<this page>`. It
replaces the fixed "Not signed in" and the dead button. Two vitests pin both states and the return path.

**CSS.** One rule, `header > * { min-width: 0; overflow-wrap: anywhere; }`. The bar prints `Pod <id>` from the address, which is as
long as whoever typed it; an unbroken id was a flex item that could not shrink and would have widened the page at 390 px. Everything
else read clean on paper (cards, chips, buttons, `pre` and `time` wrap by `overflow-wrap: anywhere`; the textarea is 100% wide with
border-box; the body is padded, not margined). No rule hides overflow anywhere, so the clipped-text check passes today by
construction and guards the future.

**Evidence.** vitest web 97 passed (2 new). `bun run check:types` clean, including tsc over web-e2e. `playwright test -c web-e2e
--list` enumerates 22 tests (11 per project). `make entropy`, `make private`, `make check-gen` green. Web cap 1,810 -> 1,820 (the tree
measures 1,817; new cap note). The specs themselves have not run: browsers are installed in CI only, so the first run is the PR's
`browser` job.
