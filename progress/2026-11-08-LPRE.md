# LPRE: land reads CI instead of re-running the preflight

**Changed.** `scripts/land.mjs` skips the local preflight when CI already proved the merge result. The decision is two pure functions in
`scripts/land-decide.mjs`: `requiredChecks` (the list comes from the branch rules, with classic protection as fallback, never from the PR) and
`ciProof`. The skip needs all of: the tree of GitHub's merge ref equals the merge-result tree the decision computed; every required check has a
run that is completed with conclusion success; every run of a required name was made by the Actions app; every read worked. Anything else runs
the preflight exactly as before. The bootstrap land and `--preflight-only` never skip. The land output and the LANDED note say
`CI proved merge tree <8>` or `local preflight`, so the two paths are countable.

**Why trees.** A merge ref built on an older main has a different tree, so the skip is refused rather than trusting a SHA.

**Evidence.** Cases are in `check-land.mjs` (pure) and `check-land-e2e.mjs` (scripted gh); they were red first. Mutants and gates are in the
builder report.

**Follow-up.** Count `CI proved merge tree` against `local preflight` in the ledger after a day of lands.
