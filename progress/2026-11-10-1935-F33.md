# F33 · one command installs Jellymoon on a Mac (2026-11-10)

**What changed.** `install.sh` (download for the chip, checksum, `~/Applications` and `~/.local/bin`, no sudo, rerun
to update), `app/macos/bundle.sh` (the bundle, ad-hoc signed, and the archive), `.github/workflows/release.yml`, and
`jellymoon uninstall` in core. ADR 0013 point 7 records the one test that runs `sh`, Mac only.

**Evidence.** `cargo test -p jellymoon --test f33`: 7 passed on a Mac, against a release the test makes with
`bundle.sh` and serves as `file://`, with `HOME` and `TMPDIR` in scratch folders.

**What's next.** Run the release workflow by hand once, then tag `v0.1.0`; a person installs on a clean Mac. F29 puts
its hook removal in `remove_delivery_hook`. The app needs a start with no arguments before a double click shows a page.

**Surprising.** The Mac's `tar` carries the quarantine flag inside an archive, so the test of taking it off is real.
`codesign` gives the same binary a different signature as a bundle's executable, so the two copies differ in bytes.
