# F40, the follow-up after its gate (PR 135 and the words PR after it)

- **Done, PR 135.** A look that took a run for one nothing holds reads the record again behind the mark, and
  gives the wish the end the run wrote meanwhile. With the copy gone and no end yet, it reads the record again
  for one second at most before it writes cut off (`run/end.rs`, `written`; `docs/development/run.md`, "A look
  between the end of the copy and the end in the record"). A run found too old and cut off before its copy went
  has a test that makes `jellymoon run` write the record (`tests/f39/limits.rs`).
- **Measured by the gate.** Live run, `run.lock` at mode 000, agent let finish, one page 0 to 75 ms after: the
  record ended `completed` with the wish written cut off in 7 of 24 rounds before the wait, and in 0 of 72 after.
- **Done, the words PR.** The gone copy's line says what was committed "was on the branch", since a branch can
  be removed by hand. A `jellymoon run` that ends after a look told its wish says so, exit 1 as before. The
  first test of `tests/f40/late.rs` asserts the record had no end when its page was started.
- **Decided.** The record's end is written only after the wish took it. So while the day's wishes cannot be
  written, the one-second wait is paid again on every look, once for each such run.
- **Open, its own gated PR.** `jellymoon run`, when nothing ran (`crates/jellymoon-core/src/run.rs`, the branch
  that calls `record::unstarted` and `copy::take_back`), writes the wish back first. Killed between that and
  `take_back`, with the day not locked, it leaves a copy, its branch and `runs/<id>` that no wish names. Every
  look starts from a wish, and `copy clean` does not take such a copy back: `--outcome failed` marks it, to be
  pruned once five newer failed copies exist; `--outcome completed` removes the folder and keeps the branch and
  the run's folder. Read, not run.
- **Open.** A run whose look told the wish `done` first still exits 1. A look whose mark lands before the run's
  commit makes that run end `failed` ("its work could not be committed"). Neither has a test. Linux and Windows
  are run by CI only; Windows is linted here without linking.
- **Suggested skills.** `tdd` for the orphan copy, then `make-pr-easy-to-review`; the PR waits for `GATE: PASS`.
