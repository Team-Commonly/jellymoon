# F52: what its gate found

On branch `f52-fix`, one commit on top of `4373280`. The account is `docs/development/wish.md` ("What is kept"),
`run.md` ("An answer") and ADR 0018, "Found while building F52".

## What changed

- **The door.** The reading across a line break had taken the place of the older reading. A word of 30 letters
  and digits on the line before a private key's first line took that line with it, the key was no longer found,
  and its body was kept. Both readings are now made, and a word is kept only where both keep it (`still.rs`,
  `both`). The test over 4000 made-up texts holds the rule: nothing the older reading replaced is kept.
- **Only marks.** Words of which cleaning leaves nothing but `[redacted]` are refused in one sentence by `wish`,
  a heard wish, `run answer`, `rule` and a tap that settles. A file that already holds such a wish is still read.
- **The run's lock** of a run that asks is a file that stays, as `runs/keep.lock` and `runs/going.lock` do. An
  answer or a toss lets go of it and does not remove it; a run that ends asking leaves it.
- **A lost session** is told by the harness's words in a result's `errors` (a list of texts) and on stderr, and
  no longer by the words anywhere in a result line.
- **An answer for a linked copy** has its test: the copy's name a link, and `copies` a link.

## What the next session should know: open rows

1. That the real harness's result carries `No conversation found with session ID` in `errors`, as a list of
   texts, was not measured in this build. Stderr is still read, and the coordinator's measurement of a session
   removed from the store should be made again on this commit.
2. An agent's question that is only marks is kept, as the mark: the finding named what a person makes.
3. A key split by a break beside an escape sequence that holds a space is kept in two pieces (`wish.md`, "Not
   closed"), and so is one split by a break with a space or a tab beside it.
4. A look takes a run's lock for a moment, so an answer at that instant can be refused as held by another
   command; a toss of a run that asks counts as one of the three while it works (`run.md`, "An answer").
5. A record written by hand can name any session of the shape core makes (`run.md`, "What is read back").
6. The lock's file of a run that was answered and then finished stays in `runs/<id>` until the run's folder goes.
