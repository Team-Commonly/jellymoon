# CPORT r1: review fixes for the pod-state server

**Changed.** A failed tick no longer leaves the single timer unarmed: every pod's tick is settled, failures are logged,
and the timer re-arms in a finally. A failed pod_create writes no row; a user, a computer and its token are written in one
transaction; the test bearer is compared in constant time; ENV=local is refused with DATABASE_URL unless JM_PG_SCHEMA marks
a throwaway schema. TestF02 skips only its directory-content check on Postgres, out loud, with the reason in the contract doc.

**Evidence.** Five new tests were red first (tick, pod_create, user and token, guards). The review's five mutants are each
caught now: boot apply, persist-before-emit, wake-seed counter, bearer check, skipped `op` save.

**Next.** CI's Postgres run is the first real-Postgres execution; read its log for the `STEP PARTLY SKIPPED` line.

**Surprising.** A pod kept the clock it was built with, so a test could not move it; pods now ask the hub each time.
