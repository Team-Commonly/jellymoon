## What the first builder must know

- **`unsafe` is forbidden in the whole workspace**, and every system interface here needs it. The design puts it
  in one file, `crates/ear/src/mac.rs`, in a new crate with its own `[lints]` table. F59 adds the xtask rule that
  refuses any other crate leaving the workspace's lints, the crate's budget, and the `[depends]` and `[forbidden]`
  lines in `entropy.toml`.
- **The app must never ask the system for speech outside a bundle.** Without `NSSpeechRecognitionUsageDescription`
  the process is killed. So the shell reads the bundle's `Info.plist` as a file first (F60), and the `ear` binary
  refuses with `NotBundled` (F59). A test or a `cargo run` can then never reach the crash.
- **Time is data in core.** `jellymoon hear` reads `tick` events and no clock, so no test waits four seconds.
- **A heard wish is not a made wish** until its four seconds end. A made wish cannot be taken back, so nothing
  may be written before then.
- **The page's window closing quits the app today** (`app/src/window.rs`). F57 changes that; `JELLYMOON_QUIT_AFTER`
  must still end the app, since tests rely on it.
- **`global-hotkey` is for the Mac and Windows only**: on Linux it would bring X11 packages. Put it in a
  `[target.*]` table and check the Linux CI job still builds the shell.
- **F55, F58, F59, F60 and F61 wait for `GATE: PASS`** before they merge: each is a new way to start a run, or
  opens the microphone.
- F56 and F57 can be built beside F59 once F55 is in.

## Three spikes first, each thrown away (the ADR has them in full)

1. The ear from Rust in a bundle signed as a release is: both prompts, on-device English and Chinese, how long
   and how wrong, and what a second build does to the grants. It decides Apple's recognizer against Whisper, and
   blocks F59.
2. The key inside GPUI's loop at the pin, with another app in front: press and release both, an input method
   composing, another app holding the same key.
3. A see-through pop-up window with no focus: does it bring the app forward, sit over a full-screen app, show a
   frame, take clicks in its see-through part; does the app live with the page closed.

## Open, and not this unit's

- **A person who only uses Jellymoon has no project on their second day**: a project is a folder typed in that
  day, and the reader leaves out a run's copy. Voice makes this the first thing a new person meets. It needs a
  note of its own before voice is announced (ADR 0019, "Risks left open", 1).
- **A Developer ID.** Under ad hoc signing a grant does not carry over an update. Only the owner can decide to
  pay for a signature.
- **The default key**, Control+Shift+Space, is the owner's to overrule.
