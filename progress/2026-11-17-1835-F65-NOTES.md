## What was built

1. **A wish for a name an earlier build kept, when the list cannot be used.** `project::lists` no longer
   answers false for a list that cannot be used: it passes the list's refusal on, and `wish` says it. Only a
   name as it is kept that holds something unseen asks the list, so every other name gets the name's sentence
   as before, whatever the list is.
2. **`project forget` of such a name cannot be undone.** `project.md` says so under `forget`. The refusal of
   the later `project add --repo` could not know that an earlier build listed this very folder: the line is
   gone. It can know that the folder's last name is one cleaning leaves that holds a character nobody sees,
   which only an earlier build kept. So it says that, and that renaming the folder is the way; `project.md`
   says what the refusal can and cannot know. Every other name that is refused keeps the old sentence.
3. **Two halves of one sentence.** `after` in `project/new.rs` puts `, so nothing was listed` where the
   refusal said `, so what was made was taken back and nothing was listed`, when the folder could not be
   removed. The file system's sentence (`SPELLED`) holds the same words and is mended the same way.
4. **A making whose folder another command listed.** When a making finds its file gone, the folder at the
   name is the made one still (the system's mark is as it was), and the list holds the name for that very
   folder, it prints the line the list holds, says the new sentence on stderr and exits 0. It writes nothing
   and removes nothing. Exit 0 is the truthful reading: this command made the folder and the repo, the list
   holds the project for that folder, so everything `project new` promises holds, and a line a hand wrote for
   the folder being made already ends a making as a made project. An exit of 1 would read as "nothing was
   made". The day printed is the list's, as this command did not list it. `new_project` now returns the
   project and what the making has to say of it that is no refusal.
5. `entropy.toml`: the sentence in core's comment that F77's tests "are within the binary's budget as it
   stood" is gone.
6. `page.md` ("The call") names `CLAUDE_CODE_OAUTH_TOKEN`, `CLAUDE_CODE_USE_BEDROCK` and `ANTHROPIC_API_KEY`;
   `README.md` has one sentence after "under your own sign-in". The two backticked lists F77's tests match
   are untouched.
