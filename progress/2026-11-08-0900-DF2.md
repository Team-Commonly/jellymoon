# DF2: daemon liveness (run token expiry, half-open pod socket)

**Changed.** A run's agent is stopped at the claim's `expiresAt` (run ends `failed`, process group gone). A pod socket that
stays silent for 45 s is dropped and the reconnect loop dials again; every heartbeat is followed by a ping, and any frame counts
as proof of life.

**Evidence.** Each fix has a red test committed first: a hung agent still running 8 s past `expiresAt`, and a silent server
that got one connection in 6 s. Removing either deadline fails its test.

**Next.** Both local servers answer pings over 75 s idle (measured in review). Measure the hosted edge the same way; if it
does not pong, a healthy idle socket reconnects every 45 s.

**Surprising.** The existing silent-socket test helper already modelled a half-open connection; only the client side lacked a deadline.
