# WSP progress (2026-11-08-0940 UTC)

**What changed.** Each run gets its own working directory under `<config dir>-workspaces`: a fresh empty dir, or a git worktree of the agent's `--repo` on a per-run branch. It is passed as `session/new`'s cwd, removed when the run completes, kept (newest 5) when it fails, and stale ones are swept at daemon start. Cleanup refuses any path that is not a run directory directly under the root. New package `daemon/internal/workspace`; wiring in `run.go`, `daemon.go`, `control.go`, `cli.go`, `config.go`. Decision: ADR 0005 update.

**Evidence.** Unit tests in `daemon/internal/workspace` and `daemon/internal/daemon`, plus one new step in TestF09. Three mutants (cleanup skipped, sweep skipped, root check removed) each fail an assertion.

**What's next.** The real harness adapters; `run.stop`; `run.toolcall`.

**Surprising.** Removing a worktree's directory leaves its record and branch in the repo, so the guard reads the repo's git dir and the branch from the worktree before deleting, and prunes after.
