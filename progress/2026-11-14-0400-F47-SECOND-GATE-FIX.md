## What changed

  yes was given under. Core names each in a text of its own and counts none; past six, a page has no yes.
- **A name not printed as it is.** `Waits` has a new part, `plain`: whether every such name is printed as git
  keeps it, byte for byte. Work with one that is not (a name that looks like a credential, printed `[redacted]`)
  has no yes on a page, in the same sentence as work past six. The sentence no longer speaks of `--ask`.
- **The kit** places a text note's options only under a body drawn whole, and plans such a note with that room.
- **The names bind.** The tap carries them, and the keep checks them as a set under its lock.
