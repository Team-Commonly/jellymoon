no page and no wish said aloud makes one. A new wish for a typed-in folder of such a name that is on no list is
refused, in the `--project takes one folder's name…` sentence: taking it would let a new name of that kind in

## Windows, which was not run here

There is no `cfg(windows)` code. `cfg(unix)` holds the file's mode (code and its assertions), the link tests
(F3, T4) and the tests that close a folder to writing (N1, L2, L3, the list that cannot be written): on Windows
those rules have no test. `tidy` compares a real path with the list's own form of one (no `\\?\`), as the
take-back does. CI proves the rest.
