# FLAKE-HOLD

TestFakeAgentHoldStaysUp waited for the fake agent's recorded prompt behind a fixed 5 s wall-clock deadline
(e2e/fakeagent_hold_test.go, the polling loop after the stdin write). Under host load a slow process start can beat it.

Fix: the loop now waits on the condition. It leaves when the record names the prompt, and fails at once if the agent
exits first. No clock bounds it; go test's own timeout catches a hang. The 500 ms stays-up window is unchanged: load
only makes it more lenient.

Measured on one adapter, host load about 21: 0/20 failures before (the flake did not reproduce), 0/20 after.
Gates run: the test, make entropy, make private.
