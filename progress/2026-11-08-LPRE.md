# LPRE: land reads CI instead of re-running the preflight

**Changed.** `scripts/land.mjs` skips the local preflight when CI already proved the exact merge commit. Land builds that commit itself
(`git commit-tree <merge-result tree> -p <main tip> -p <head>`), pushes it to `refs/heads/land/<n>` (ci.yml also runs on `land/**`), and
polls every 20 s, up to 15 minutes, for the required checks on that commit. The decision is pure functions in `scripts/land-decide.mjs`:
`requiredChecks` (the list comes from the branch rules, with classic protection as fallback, never from the PR), `ciProof` and `landRef`.
The skip needs all of: GitHub's tree for the pushed commit equals the merge-result tree the decision computed; every required check has a run
that is completed with conclusion success; every run of a required name was made by the Actions app (a same-named run from another app is
ignored); every read worked. Anything else (red, cancelled, skipped, the cap, an unreadable list, a failed push) runs the preflight exactly as
before, and a land commit whose tree is not the merge result refuses. The bootstrap land, `--preflight-only` and `--dry-run` never push. The
land output and the LANDED note say `CI proved merge tree <8>` or `local preflight`, so the two paths are countable.

**The land ref.** Land only ever pushes or deletes a ref built by `landRef` (`refs/heads/land/<digits>`). A leftover `land/<n>` is reused
only when it is the land commit: the merge tree and exactly main's tip then the head as parents (the dco check reads the parents); anything
else is overwritten under a lease on that commit. The ref is deleted on every exit, including SIGINT, SIGTERM and SIGHUP.

**Why trees.** A merge ref built on an older main has a different tree, so a proof is refused rather than trusting a SHA. After the merge land
reads the merged commit's tree; if it is not the proven one the LANDED row says `TREE-MISMATCH` and land warns (it cannot be undone).

**First design, dropped.** The first pass read CI on GitHub's merge ref, which never carries check runs (runs attach to the PR head), so the skip
could not fire. LPRE2 replaced it with the land commit above.

**Evidence.** Cases are in `check-land.mjs` (pure) and `check-land-e2e.mjs` (scripted git and gh; the land/<n> logic is tested with its git
seam stubbed, never live). Mutants and gates are in the builder report.

**Follow-up.** Count `CI proved merge tree` against `local preflight` in the ledger after a day of lands.
