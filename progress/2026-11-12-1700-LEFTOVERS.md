# The leftovers of four after-merge reviews (#115, #118, #119, #120)

One ungated PR, branch `leftovers`. Nothing here changes what leaves the machine or what an agent may do on it.

## What changed

- **Smoke (#115).** `cargo xtask smoke` refuses `--release`, `-r`, `--profile`, `--target` and `--target-dir` after
  `--`, with one line, before a build: the chain runs `target/debug`. The guard test names the exact steps a `--real`
  run takes. A run first removes the `target/smoke-home-*` folders earlier runs left. It does not ask whether a pid
  lives, which needs a dependency or a different call on each system: each run holds the system's lock on
  `smoke-home-<pid>.lock`, and a home whose lock can be taken has no living run (`docs/development/smoke.md`).
  `found-off-path` moved out of `smoke/steps.rs` (395 lines, now 367) into `smoke/off_path.rs`.
- **The kept page's test (#118).** Its steps run in the test's own process, in the machine's time zone, and the
  day's lines were stamped at 16:00Z to 18:00Z: east of UTC+6 they fell on the next day, nothing was read, and the
  test still passed. The lines are stamped at 12:00Z and the test asserts the harness was called.
- **`bundle.sh` (#119).** A `MIN_MACOS` that is not `<number>`, `<number>.0` or `<number>.0.0` is refused:
  `install.sh` compares the first number only. `app/tests/bundle.rs` holds it, on a Mac.
- **Art cost (#120).**
  - A picture with no `viewBox` and a side left out is refused. This was a hole: the renderer sizes such a picture
    to what it holds, so `width="10"` and a path out to 4096 was counted as 10 by 256 and drawn at 8192 by 8192.
    With a `viewBox`, or both sides, the drawn size is the counted one (`tests/draw.rs` rasterises and compares).
  - Each number of an arc counts four (`ARC_NUMBERS`). Measured in a debug build, one picture of 1024 numbers: lines
    0.02 to 0.19 s, arcs of radius 4096 under a thin stroke 6.7 to 7.4 s. A curved variant of the heaviest-art test
    holds the limit and draws it.
  - `Theme::art_svg` sums the costs again as it re-reads the files, in `load`'s order, and gives none for a file
    that would pass a count: a file swapped after `load` cannot pass the total.
  - `read_art` returns the text with its cost; `load` no longer falls back to an empty cost.

## Not done, and why

- The sum at the draw is in `theme/load.rs`, not in `draw/sprites.rs`: `draw/` was another worker's.
- Cubic curves with control points far outside the picture cost 1.3 to 1.7 s per 1024 numbers and still count one
  for one. A count per command kind is the next step if that matters.
- `docs/development/install.md` does not name the whole-release rule: PR 137 was changing that file.
- `tests/theme.rs` fixtures changed (a `viewBox` on one, the size lists): the new refusal required it.
