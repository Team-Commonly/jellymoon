# F39: a wish starts a run, and its star appears when the run reports it finished (`jellymoon run`)

- **Done.** Core's `run` (`run.rs`, `run/child.rs`), the command, 15 tests at the binary (`tests/f39.rs` and
  `tests/f39/`) over the made-up `fake-agent`, the smoke step `run`, `docs/development/run.md`. F39 passes.
- **Decided.** Finished is a success result, `is_error` false and exit 0, all three. One run for a wish: the wish
  names its run behind the day's lock before the harness starts. A run cut off is told by the system's lock on
  `runs/<id>/run.lock`, which a page only asks about. The folder of a wish comes from that day's session logs and
  is written nowhere but the run's record.
- **Surprises.** serde reads a JSON list as a struct, field by field: `["result","error",true,[]]` was a result
  line until a test caught it. A scratch folder under a harness worktree is named after the repo above it, by the
  reader's own rule, so the test of finding a folder runs in the system's temporary folder.
