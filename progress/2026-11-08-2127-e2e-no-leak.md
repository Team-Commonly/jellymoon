# e2e-no-leak: a test run leaves no fake agent behind

Cause: the test cleanup, not the daemon. `spawn` registered `p.kill` (e2e/f08_test.go) as the cleanup, and `kill` sends
SIGKILL to the daemon's process group. The daemon starts each agent in its own group (`Setpgid`, daemon/internal/acp/acp.go),
so the kill never reached the agent, and a daemon that is killed cannot run its own shutdown. TestF11 ends with its hold-mode
agent still running (it ignores SIGTERM), so the agent is left with parent 1. TestF09 only avoided it because its last step
stops the daemon with SIGTERM. ADR 0005 holds: a daemon stopped with SIGTERM ends its agents' groups.

Red: every `par` test now fails if a process built under its temp dirs outlives it (e2e/strays_test.go, `noStrays`).
TestF11 failed with "a process outlived the test: ... fakeagent ... hold".

Green: `spawn` cleans up with `stop` (SIGCONT, SIGTERM, wait 10 s, SIGKILL only as the fallback). `kill` stays for the crash tests.

Checked: `make preflight` twice and `make e2e-a` once, all green, 0 "outlived" lines, 0 fakeagent processes after each.
Before the fix, one TestF11 run left 1. With the fix removed (cleanup back to `p.kill`) the check fails TestF11; reverted.
