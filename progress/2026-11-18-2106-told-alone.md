# Told alone: a wish that changed nothing still says what happened

## Built
- Core's door, `ended_alone` (`crates/jellymoon-core/src/run/show.rs`): how a made wish's run ended when it left no
  work to wait. `Unchanged(Option<Told>)`: it finished and changed nothing (its record's line says so, and it was not
  tossed), with the result `run show` prints. `Unfinished`: its record says it failed. None of a run that asks, was
  stopped, is going or of a wish with no run. `found` is split so `ended` gives the run and its outcome.
- `run show` prints the `result` of a run that finished and changed nothing, beside `"files":[]`: with no file every
  `change` is dropped and counted; `did`, `decided`, `unsure` pass the door and bounds as with work. No repo is asked.
  `run waiting` lists nothing of it, as before; tossed, nothing is printed of it.
- `stands(wish, alone)` (core): of a wish that needs the person because its run did not finish, two fixed sentences
  after its words.
- The app (`app/src/working.rs`, `told.rs`): opening a made wish with no work asks `ended_alone`; a result that passed
  is `told-<wish>` over the wish's own note ("This wish is done."), above it, its sentences starting with "Nothing in
  your folder was changed.". A look shows it by the rules work that waits follows (`waiting_over` now takes the
  page; `shown` counts `told-` notes so it is shown once).
- Docs: app.md, show.md ("Told alone"), run.md (what is kept), ADR 0023 dated note.
