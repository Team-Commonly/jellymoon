# Open fast: a kept page shows at once; the smoke chain runs the app's own reading; F34's review

- **Order.** `Today::first` shows the kept page before a log is opened. `Today::later` is two steps the window runs
  off its thread (`today::Next`): count the turns, then the reading call. A kept page that is read again stays on
  show under "Reading your day again…"; the waiting page is only for a day with no kept page.
- **Review of F34.** `skip.txt` fails closed: unreadable, over 64 KiB or not UTF-8 is a plain note and no call; a
  byte order mark is dropped. The kept page is written through a per-process file, 0600. A home that is not an
  absolute path is refused. `app.md` lists every flag; `install.md` says what opening the app does now.
- **Proof.** `app/tests/f34.rs` (8) and the new `f34_kept.rs` (5), over the made-up day now in `support/day.rs`.
- **Smoke.** `today` and `today-again` in `crates/xtask/src/smoke/steps.rs`: the app reads the made-up day itself
  and keeps it; again, the same pieces and no call. CI's macOS smoke run is `--window` and required.
- **Not proved.** The step test asserts on notes only: core reads the day in the test's own time zone, so it never
  asserts that the second step called the harness. The binary cases set `TZ` and do.
- **Next.** Taps (F29). The window still does not look again while it stays open.
