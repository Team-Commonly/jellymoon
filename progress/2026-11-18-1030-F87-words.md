# F87: the fixed words ask for changed lines only

## Why
The coordinator measured F87 on a real Claude Code (2026-11-18, ten wishes): the schema with its bounds is
taken, a last word is 282 to 606 bytes, and of 11 `change` pieces 6 passed and 5 were dropped. Every dropped
piece quoted exactly but carried unchanged lines for context, which fail the rule that a quoted line is there more
often on its side (`run/told.rs`, `change`).

## Built
- `PROMPT` (`run.rs`) and its copy in `tests/f39/line.rs`: `before` holds only lines gone or read differently,
  `after` only lines new or read differently; never an unchanged line for context; an empty side for lines only
  added or only removed. "A new file has no `before`" is folded into that.
- `told.rs` already passes an empty side on a changed file (one line at least in all; each side checked line by
  line), so it is not touched.
- `run.md`: the words, why they ask for changed lines only, and "Measured on a real Claude Code" filled with the
  first numbers and one line left for the coordinator's second measure.

## Red, mutations
No new behaviour of code: the byte-for-byte line of `tests/f39.rs` holds the new words. No mutation run.
