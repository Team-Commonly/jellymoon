# METIMEOUT: the boot check no longer waits forever on /v1/me

**Changed.**
- `web/src/http.ts`: `bootSignedIn(http, timeoutMs)` decides signed in or out. Nobody, an unreachable server and a silent one all count as signed out. After `BOOT_ME_TIMEOUT_MS` (5 s) it aborts the request through an `AbortSignal` and also races the answer, so a client that ignores the signal still settles. `Http.me` takes an optional signal and `browserHttp.me` passes it to `fetch`.
- `web/src/main.tsx`: thin glue, calls `bootSignedIn(browserHttp)`. `App` props are unchanged.
- Cap: web 1,820 -> 1,890, with one note in `docs/entropy/caps/`.

**Evidence.** `web/src/boot.test.ts` covers a person, nobody, a rejected call, a call that never settles (fake timers: still pending at 4,999 ms, signed out and aborted at 5,000 ms) and no timer left behind. `web/src/http.test.ts` checks the signal reaches `fetch`. The new tests were red (`bootSignedIn is not a function`) before the change and green after.
