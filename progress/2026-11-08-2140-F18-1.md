# F18 PR 1: the web package, shell, socket store, card model and key map

**Changed.** A new `web/` package (React, Vite, TypeScript). Four pure, unit-tested modules: the per-pod socket store
(`store.ts`), the card model and needs-you selector (`cards.ts`), the key map (`keymap.ts`), and a shell with a top bar and
a `/pod/:id` placeholder (`App.tsx`). Types come from `gen/ts/protocol.ts`; nothing is copied. Dependencies are declared in
the root `package.json`, as the worker and server do, and pinned exactly.

**Evidence.** The tests were committed red first (39 failing against stubs), then green. Three mutants were each caught: the
seq guard dropped, an optimistic ruling, the text-field guard dropped.

**Next.** `/pod/:id` cards and the needs-you filter on top of these modules (PR 2). A real WebSocket connector is not here: the
store takes an injected `connect`, and the browser socket needs cookie auth on the pod socket first.

**Surprising.** The commit hook runs the whole entropy gate (knip included), so a test-first commit cannot import missing
modules; the red commit uses throwing stubs instead.
