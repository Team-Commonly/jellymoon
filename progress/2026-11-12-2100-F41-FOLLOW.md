# The findings of F41's gate (PR 138), fixed

One gated PR, branch `f41-follow`: it changes what an agent may do on the machine (where a run may be started,
what a look removes, which agents a run ends). F41's gate passed with eight findings that did not block; this
closes them. Docs: `docs/development/run.md` ("A run that was never started", "A copy nothing names", "A run
started apart", "Three runs at once") and `copy.md`.

## What changed

- **1 and 8, the folder a name leads to.** A folder found in a log is resolved once (`run/place.rs`): its last
  name after every link is followed must be the wish's project, the owner is asked of the resolved folder, and
  the copy is made of that same path. `tests/f41/named.rs`.
- **2, a harness that never begins a run.** The wish is told: no run, `needs_you`, and one of three fixed lines
  in `why` (`run/never.rs`). The asker waits until the run's record says the stream began, or 3 seconds, before
  it says a run is going, and otherwise prints the line the wish keeps. Chosen over a probe of the harness
  before the copy: nothing new is started or measured, and the page, which draws the wish, is right by itself.
  `tests/f41/never.rs`; ten F39 tests now expect the told wish in place of the wish as it was made.
- **3, a copy nothing names.** Every `jellymoon run` holds `runs/<id>/start.lock` from the id's taking to its
  end. A page, or a run before it counts, takes back a copy whose start lock nothing holds and no wish names
  (`run/left.rs`); one with a child in its record is kept and marked failed; a branch with a commit of its own
  is kept. `tests/f41/left.rs`.
- **4, the cap counts commands.** Done in code: the same pass kills the child each left run's record names, by
  pid and mark, before the count. Unix only; the doc says Windows stops nothing.
- **5.** The sentence on Unix descriptors is in the Windows bullet of "A run started apart".
- **6.** A folder and a link at `runs/going.lock` (`tests/f41/refused.rs`); the asker's line cleaned and cut, a
  program not named by a full path, and the started command's own process group (`tests/f41/line.rs`).
- **7.** An empty `--skip` value is no name, so the started command gets no `--skip`. Same test, read with `ps`.

Mutations put in and caught, then taken out: the pass switched off, the empty `--skip` rule, the full-path
check, the asker's wait, the process group, the wish's kept reason.

## Not closed

- A command killed while git was still making its copy leaves the branch and git's registration in the repo.
- Between resolving a log's folder and git reading it, a folder on the path can still be swapped for a link.
- With no harness found at all, a wish made with `--run` stays `working`, with the reason printed only.
- A too-old harness that takes over 3 seconds to refuse is first said to be going; the wish is right after.
- Runs cut off by a build older than the start lock are ended by the look at their wish only.
- On Windows the new tests that read `ps` or need signals are skipped, and say so.
