# The harness is found when the app is opened from Finder (2026-11-11)

**What changed.** Core looks for `claude` on `PATH`, then in `~/.local/bin`, `~/.claude/local`, `/opt/homebrew/bin`
and `/usr/local/bin` (`crates/jellymoon-core/src/find.rs`, `docs/development/page.md`), for the command and the app
alike. A candidate there is passed over when others can write to its file or everyone can write to its folder. A
harness found off `PATH` gets `PATH` plus its own folder and those places. The home is `HOME` as a full path and
nothing else: core reads it itself. The "not found" line and the app's note name the places looked in.

**Evidence.** `cargo test -p jellymoon --test harness`: 9 passed, with `PATH` an empty folder and a temporary home.
F27's 12 and F34's tests pass. `cargo xtask smoke` has a `found-off-path` step. Budgets equal measured counts.

**What's next.** A person double-clicks the installed app on a Mac with a real Claude Code: no test here does that.

**Surprising.** Rust's `home_dir()` answers from the account record when `HOME` is empty, so a "sealed" test run
reached a real harness. A file copied from a build keeps its mode, group-writable under a umask of 002.
