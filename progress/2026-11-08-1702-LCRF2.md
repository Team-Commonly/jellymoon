# LCRF2: land follow-ups

**Changed.** Four land fixes, each from a real refusal or review on 11-08.
- Latest run per check name (`checkRuns` in `scripts/land-decide.mjs`). A name is judged by its latest run: latest `started_at`, ties
  broken by the higher run id (ids only grow; a cancelled run can share or lack a start time). Runs that tie on both are all judged, so
  a bad one among them refuses. A cancelled run with no later run of that name, and a later failure after a success, still refuse.
  The check-runs query now also reads `id` and `started_at`.
- Draft PRs (`draftGate` in `scripts/land.mjs`) are refused with `#<n> is a draft (nothing merged)` right after the trust gate and
  before any land ref is pushed. An unreported draft state counts as a draft. The pre-merge re-read checks it again.
- Tree mismatch: the LANDED row with `TREE-MISMATCH` and the warning stay; land then refuses (non-zero exit) naming both trees and
  never prints "safe to delete".
- `docs/development/landing.md`: the leftover `land/<n>` rule, the signal cleanup, and items 1 to 3.

**Tests.** `scripts/check-land.mjs` (six cases for item 1), `scripts/check-land-e2e.mjs` (draft x3, mismatch extended). Each was red
before its change and green after.
