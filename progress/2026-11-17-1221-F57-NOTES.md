# F57 notes: the blocker and the notes of the review of the jellyfish's window

**What changed.** On branch `f57-notes`, on main `bb2a384`. One commit; no row of `feature_list.json` changes.

- **No harness has three sentences, not one.** The short one ("no `claude` program was found (JELLYMOON_CLAUDE
  names one)") was said for every missing harness, so it was untrue when a `claude` had been found and passed
  over. It is now kept for a search that found nothing with a home to look in. A program passed over, and a start
  with no home, have a fixed sentence each, with no path in it; both are in `Hearing::refusals()`. `find.rs` gives
  what a search missed as data (`Missed`), and `Error::NoHarness` says what it said before.
- **The jellyfish asks which day it is at each look** (`shell::jelly_look`), so past midnight it shows the new
  day's runs. A day named with `--date` stays.
- **A bubble removed from outside is opened again** at the next words, and an open that fails is said once on
  stderr for as long as it fails.
- **`--theme` refuses as `--page` and `--jelly` do**: the file's last name only, and for a file that cannot be
  opened the same fixed words, after what `--theme` takes. The kit has `ThemeError::NoFile` for it.
- **What a frame painted is data**: `EdgeView::painted()` gives each run's ink and clipped box.
- **Gone**: `EdgeView::set_theme`, `popup::Kind` and the printed `"kind":"pop_up"` of a window's `opens`,
  `Opened::page`, two copies of `apart`. `Tapped::None` is `Tapped::Nothing`, still printed `none`.
- **Docs**: `hear.md` says what the list of refusals holds; `app.md` has four things for a person at a screen,
  the Dock among them, and says no test sees Quit end the process or the app come to the front; the kit's README
  has an open row for the bubble's inks with the four measured cases.

**The evidence.** Red first: the two new sentences at the binary (`tests/f55/started.rs`), the exact list
(`app/tests/f56/words.rs`), the count in core's `tests/hear.rs`, `--theme`'s refusals (`tests/f57.rs`,
`tests/f32.rs`), the bubble removed from outside and the clock moved past midnight (`tests/f57/window.rs`).

**What's next.** Nothing of this change. The login shell's `claude` is F67's.

**Surprising.**

  the app is opened again. `app.md` says so; nothing was built for it.
- One mutation survives: in `main.rs`, giving the look the opening day always, as before. `main.rs` opens a
  window, so no test reaches that line; the rule itself is tested through `jelly_look`.
- No open fails on GPUI's test platform, so "said once" is a pure function with a unit test, and that a real
  failed open reaches stderr was not seen.

  of `Room::primary` cannot tell the room a Dock leaves from the whole screen.

  function a run no layout gives.
