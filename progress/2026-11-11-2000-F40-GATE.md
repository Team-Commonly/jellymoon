# F40's gate, round 1 (`f40`)

- **Done.** Ten findings, one commit each. A file of the home that is not a plain file keeps neither a stop nor a
  page waiting. An agent that reports a success and exits 0 at the interrupt is cancelled. The test of an agent
  deaf to the interrupt fails without the stop signal. The child a cut-off run left is killed whatever its record
  says. A stop prints nothing of a record whose end it does not believe. A request that is a folder or a link
  stops the run, and one left before the agent is started starts none. A stopped run that prints past the cap is
  cancelled. A wish that names another wish's run has no say over it. F40 has 26 tests at the binary.
- **Decided.** A wish changed by hand to name another wish's run is kept as it was written, and nothing is
  written on its word; one made to say `working` is drawn as `needs_you` on every look
  (`docs/development/run.md`, "A wish that names another wish's run"). A run is another wish's only when the wish its record names does name it: a record
  changed to name a wish that does not is still a cut-off run of its own wish, as F39's gate decided. A record
  that has an end is never written again, believed or not.
- **Not caught by a test.** The 65 seconds a stop waits: only the test's own shorter wait is run. That a stopped
  child's exit 0 is not read as a success in `child.rs`: `settle` ignores it for a stopped child either way.
- **After the handoff.** A wish made to name another wish's run is drawn `needs_you`, never `working`. The copy
  of a run whose believed end is `failed` or `cancelled` is marked failed by the look that finds it. Two F39
  tests (`a_run_that_never_ends_is_stopped_at_its_limit_and_has_failed`,
  `a_stream_that_does_not_start_as_a_run_s_does_is_stopped_at_once_and_is_never_a_star`) no longer time the
  agent's start: two F39 binaries at once pass. Main was merged in: every open of `runs/clean.lock` is in
  `copy/hold.rs` and refuses what is not a plain file; a look kills the child, marks the copy of any run that
  did not finish behind that lock, waited for 3 seconds, and only then tells the wish.
- **Open.** Linux and Windows were run by CI only, and not since the gate's fixes. Under another worktree's test
  loop, F38's `a_git_that_never_returns_is_killed_and_no_half_made_copy_is_left` failed once ("the made-up git
  never got to its sleep"); alone it passes.
