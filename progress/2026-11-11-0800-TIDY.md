# Tidy before the first release: the leftovers of the two gate reviews (2026-11-11)

- **The installer's folders.** `install.sh` makes the folders it has to make 0755 whatever the umask, so the app can
  offer "Turn on delivery" for the command it placed; a bin folder that was there and is open is said in one closing
  line (`tests/f33/modes.rs`, the script run with `umask 002` as the first line of its input).
- **Tests that say why.** Under a folder that group or others can write to, the delivery tests leave out only the
  half where the command is taken (`open_above`), and make their own folders 0755. A setgid bit the system drops
  (a file under `/tmp` on a Mac) is said and left out. New cases: no home, a 32-link chain, an empty statement.
- **Small ones.** `layout` prints a run's `size`; both stop lines end with the way out; a core test walks all 485.
- **Three changes PR 123 made that it did not state in full.** A tab inside a name in `skip.txt` now stops the run
  (it is a control character inside a name). A `--skip` value that names a folder by a whole name holding a joiner
  or a variation selector is now exit 2: name a part without it. Control white space at the end of a list name,
  which stopped the run before, is now dropped and the name honoured.
- **Not proved.** On a Mac the system stops at 32 links before core counts a 33rd; Linux reaches core's own limit.
