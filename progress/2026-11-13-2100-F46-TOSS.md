# F46: `jellymoon run toss`

On branch `f46-toss`, one commit on top of `main` with F45 merged (`d6f7b89`). It is the one command that deletes in a person's repo, so a
fresh gate reads it before it merges. The whole account is `docs/development/toss.md`; ADR 0017 has what was
decided while it was built ("Found while building F46").

## What was built

`jellymoon run toss --wish <id>`. Core's part is `run/toss.rs` (the record and every printed word),
`copy/keep/toss.rs` (the delete of the run's own name, behind the lock a keep holds) and
`copy/clean.rs`'s `drop_copy` (a kept copy removed). The binary parses one word and prints.

- The record takes `work: tossed` and `tossed`, the commit, before anything goes. Work that waits is checked
  whole before that, and a refusal changes nothing.
- One name is deleted: `git update-ref --no-deref -d refs/heads/jellymoon/run-<id> <commit>`, with a keep's git.
- A run that did not finish loses its kept copy, and its branch only while that is still at the run's start.
- A record that names no commit is tossed with its branch left, in fixed words.
- A keep and a toss share one lock and one cut hook (`busy::cut`), which is not compiled into a release.

## What the coordinator should know

1. **The ADR's reading, not the row's.** The row says a failed run's branch goes "by the same rule". A branch
   that is not at the record's `start`, and a branch no record names a commit for, are left.
2. **`tossed` in what is printed is whether this command changed anything.** A second toss is exit 0 with
   `tossed: false`. A toss of kept work, and of work a cut-off keep had landed, is a refusal, exit 1.
3. **A branch that is not in the repo is no refusal**: the record and the wish are written.
4. **`run keep`'s busy sentence changed** to `another keep or toss is at work in this home`. A lock that could
   not be made or taken has one sentence, a keep's and a toss's: `the lock a keep or a toss holds
   (runs/keep.lock) could not be made or taken in this home`.
5. **`run stop` prints `its copy is no longer kept`** of an ended run when nothing is at the copy's name.
6. **`copy/back.rs`** reads the tip as a look does; `GIT_GRAFT_FILE` is a whole path; a question git answers
   "not there" while it warns on stderr is "not there".
7. **Not closed** is a section of `toss.md`: a cut between the delete and the putting back of a name a checkout
   came to stand on, a keep killed inside `git merge`, work a cut-off keep landed on a `HEAD` the toss is not asked in, a branch a toss left, a copy whose record was removed by
   hand, the stored line of a failed run.
8. **A branch named as a run's is, in either case of the letters, is none of the person's** (F45's rule,
   `copy::runs`). One that holds the commit a cut-off keep meant is no landing, and only the run's own name is
   deleted. A checkout whose `HEAD` names the run's branch under another case of its letters stands on it
   (`copy/back.rs`, `stands`): a toss, a keep and a copy's take-back all leave the branch.
9. **Work kept on no named branch** (`onto: HEAD`, the run's branch left by the keep) is kept work: a toss is
   refused in the words of kept work, and the branch stays.

## Mutations

62 single changes to `copy/keep/toss.rs`, `run/toss.rs`, `copy/clean.rs`, `copy/back.rs`, `copy/git.rs` and
`busy.rs`, each put back. 45 were caught at once. Eight more are caught by tests written for them (a repo that
cannot be asked who stands on the branch, a record that cannot be written, a start that is not the commit's
parent, `--no-deref` on the delete, half a keep in an unfinished run's record, another wish's run, a killed
run, a home with no clean lock). One guard that nothing could reach was taken out. Eight are alive:

| Change | Why nothing fails |
|---|---|
| the putting back of a name without its old value of zeros | only a third hand making the name between two of git's steps would tell |
| the wish no longer names this run: not asked | a made wish names one run for life today |
| `changed` without `wrote` | a first toss always tells the wish too |
| `changed` without the copy having gone | a copy is only there after the record says tossed when the wish is untold as well |
| the wish working, or a record with no outcome: not refused | a toss gives every run nothing holds its end first |
| the wish told again when it was told | the same words are written |
| `GIT_GRAFT_FILE` by a relative name | git reads it from the folder it is started in, which is that same empty folder |
| "not there" for an asked question that printed something | no question core asks prints on stdout when it exits 1 |
