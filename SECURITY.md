# Security policy

## Reporting a vulnerability
Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.
Please do not open a public issue or pull request for it, and do not post details anywhere else first.

## Scope
This repository's code: the schema and generated contracts, the pod core, the Worker, the daemon, the CLI and MCP adapters,
and the scripts and CI that build and land them. A flaw in a third-party dependency belongs with that project; tell us too
if Jellymoon's use of it makes the flaw reachable.

## What to expect
Fixes for live issues are released before details are discussed. We will acknowledge the report, work with you on a fix, and
agree when it is safe to publish an advisory. Please keep the details private until then.
